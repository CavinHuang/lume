C. Popover 锚点弹出

从侧边栏搜索按钮位置弹出浮层，也支持 Ctrl+K 居中弹出

方案 A (居中) 优势

  • 用户最熟悉的模式 (VS Code / Cursor)
  • 不依赖侧边栏状态（折叠时也能用）
  • 展示空间大，可扩展更多命令

方案 A 劣势

  • 遮挡当前内容
  • 与侧边栏搜索按钮的关系需额外设计
