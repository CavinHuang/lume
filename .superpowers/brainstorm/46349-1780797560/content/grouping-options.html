Provider 分组 UI 方案

选择左侧 Provider 列表中如何展示分组

方案 A：分类标签栏（推荐）
全部 编程套餐 国内平台 海外平台 中转/聚合 本地/其他
🔍 搜索供应商
🟢 Kimi Code Plan 已配置
⚪ 阿里云 Coding Plan 未配置
⚪ 智谱 GLM Coding Plan 未配置

A：分类标签栏

用标签栏替换当前的"全部/已配置/未配置"筛选，点击不同标签切换分组。搜索框在标签下方。

优点

  • 操作直观，一键切换
  • 视觉清晰，占用空间少
  • 可与搜索组合使用

缺点

  • 标签多时可能换行
方案 B：可折叠分组列表
🔍 搜索供应商
▼ 国内编程套餐 2/6
🟢 Kimi Code Plan 已配置
⚪ 阿里云 Coding Plan 未配置
▶ 国内平台 1/8
▶ 海外平台 0/4

B：可折叠分组列表

保留完整的 Provider 列表，用可折叠的分组标题组织。每个分组显示"已配置/总数"。

优点

  • 一览全局
  • 分组信息始终可见
  • 支持展开/折叠按需查看

缺点

  • 列表较长时需要滚动
  • 分组标题占用纵向空间
方案 C：下拉选择分组 + 分段标签
全部分组 ▼
全部 已配置 未配置
🔍 搜索供应商
🟢 Kimi Code Plan 已配置

C：下拉选择 + 保留原筛选

新增分组下拉选择器，保留原有的"全部/已配置/未配置"筛选。两个维度独立叠加。

优点

  • 保留现有交互习惯
  • 分组+状态可叠加筛选

缺点

  • 两层筛选增加认知成本
  • 下拉选择需要额外点击
  • 左侧面板更拥挤
