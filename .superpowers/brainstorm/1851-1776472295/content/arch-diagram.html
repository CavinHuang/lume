设计 §1: 架构与数据流

Subagent 事件已通过父线程流式转发，前端按 runId 分组

数据流架构
SDK Engine
→
Agent Tool
→ annotate with subagent_run_id →
Parent Stream

事件消息流 (agent:stream:event)

1. assistant — 主 assistant 回复，包含 Agent tool_use
├ stream_event runId:abc — subagent 文本 delta
├ assistant runId:abc — subagent 完整消息 (含 tool_use)
├ tool_result runId:abc — subagent 工具结果
├ stream_event runId:abc — 更多 subagent delta...
└ assistant runId:abc — subagent 最终消息
2. tool_result — Agent tool 的结果（主线程）
3. assistant — 主 assistant 继续回复

前端处理逻辑

路由

检测消息是否有 subagent_run_id

有 → 写入 subagentMessagesAtom[threadId][runId]

无 → 写入 agentSDKMessagesAtom[threadId]（主线程）

渲染

SDKContentBlock 渲染 tool_use: Agent 时

→ 查找 subagentMessagesAtom 中对应 runId 的消息

→ 渲染 SubagentInlinePanel（收缩/展开双态）

嵌套

SubagentInlinePanel 内部递归使用 SDKContentBlock

子 subagent 的消息同样有 subagent_run_id 标记

递归渲染时用缩进 + 竖线表示层级
