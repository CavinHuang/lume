事件驱动自动化系统 — 架构概览

四层架构：采集 → 分析 → 建议 → 执行

系统架构图
信号源层（Signal Sources）
Agent 对话 · 用户操作 · 系统事件 · 外部服务
▼
事件总线（Event Bus）
统一事件流 · 分类路由 · 持久化存储
▼
AI 分析引擎（Pattern Analyzer）
重复检测 · 痛点识别 · 建议生成
▼
自动化引擎（Automation Engine）
建议展示 · 用户确认 · 任务调度 · 执行追踪

数据流

发现流程：
用户操作 → 信号源采集 → 写入事件总线 → AI 分析引擎检测模式 → 生成自动化建议 → 展示给用户 → 用户确认 → 创建自动化任务

执行流程：
触发条件满足 → 调度引擎启动 → Agent 执行任务 → 可调用外部工具 → 记录执行结果
