前端状态管理

Jotai Atoms：

automationsAtom: AutomationJob[]         // 所有自动化任务
suggestionsAtom: AutomationSuggestion[]     // 待处理建议
automationRunsAtom: Record<string, Run[]>    // 执行记录

监听后端通知：
automation:suggestion-new → 更新 suggestionsAtom
automation:run-completed → 更新 automationRunsAtom
automation:job-paused → 更新 automationsAtom
