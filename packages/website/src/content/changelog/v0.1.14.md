# Lume v0.1.14

> 更完整的浏览器运行时与任务执行能力，让复杂工作流更容易持续、恢复和审查。

## 🔥 Highlights

- 🌐 浏览器运行时：统一浏览器控制、实机门禁和凭据保护，浏览器自动化流程更可靠。
- 🧭 持久化 Task：任务状态、执行结果和恢复能力得到完善，长任务不再依赖一次性的内存状态。
- 🔎 Advisor 审查：支持使用第二模型审查代码，并在助手回复中展示联网检索来源。
- 🛠️ Coding Agent：完善 LSP 写操作、Web Fetch 回退和端到端编码执行闭环。

## 🚀 Features

- feat(desktop,sidecar,web,shared): 统一浏览器运行时与双后端控制，支持更稳定的浏览器实机操作。
- feat(sidecar,web,sdk): 引入持久化 Task 工具链，支持任务进度、交互状态和恢复。
- feat(desktop,sidecar,web,shared): 增加浏览器实机门禁与凭据保护，降低敏感操作风险。
- feat(sidecar,web,shared,sdk): 完善 coding agent 闭环执行、Advisor 第二模型代码审查和联网来源展示。
- feat(sdk): 接入真实 LSP 服务器与 LSPApply 写工具，并增强 web-fetch 的 reader 回退与结构化解析。

## 🐛 Bug Fixes

- 修复 TaskStop 后执行器终态竞态、TaskStore 恢复和事件回放问题。
- 修复 OpenAI Responses assistant 消息解析，统一使用 `output_text`。
- 修复本地 ONNX 嵌入模型下载超时和缓存模块拆分问题。
- 增加 Windows 凭据验证回退，并移除会打断正常流程的旧系统凭据验证链。

## 🔧 Maintenance

- 移除旧任务契约回调、旧审批执行链和已完成的临时计划，简化任务执行路径。
- 持续补充桌面端、sidecar、SDK 和 Web 行为测试，复用现有运行时与 IPC 能力，不引入新依赖。
