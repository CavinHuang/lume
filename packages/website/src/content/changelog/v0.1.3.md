# Lume v0.1.3

> 修复 Windows 安装后 sidecar 仍引用 CI 构建目录、导致应用无法完整启动的问题。

## 🔥 Highlights

- 🐛 完整启动修复: jsdom 同步 XHR worker 现在作为独立资源随安装包分发，不再读取 CI 工作区文件。
- ✅ 可迁移产物验证: sidecar、原生模块和 XHR worker 会搬到仓库外的临时安装目录后启动验证。

## 🐛 Bug Fixes

- fix(sidecar): 移除 `xhr-sync-worker.js` 和 `undici/index.js` 中残留的构建机绝对路径。
- fix(sidecar): 将 jsdom 默认样式表和同步 XHR worker 构建为完全自包含的安装资源。
- test(desktop): 打包输入、安装产物和 Electron smoke 均验证 XHR worker 存在且可启动。
