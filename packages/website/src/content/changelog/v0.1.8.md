# Lume v0.1.8

> 强化插件市场与中央 Wiki 的默认能力、权限边界和桌面端发布验证。

## 🔥 Highlights

- 🧩 插件市场：默认启用镜像源，并在镜像不可用时回退到 GitHub，插件资源与远程 SVG Logo 加载更稳定。
- 📚 中央 Wiki：普通线程可以明确使用只读 Wiki 能力，写入仍需草案确认和特权凭据。
- 🛡️ 发布可靠性：修复 Windows sidecar smoke 的标准流握手超时，改由真实安装包启动链路验证 Electron utilityProcess。

## ✨ Features

- 支持插件市场镜像配置、GitHub 回退和远程 Logo 注册。
- 优化 Wiki 能力注入、能力提示和“当前线程未获得该工具”的用户反馈。
- 补充 Wiki 读写边界的 ADR 与默认技能指导。

## 🐛 Bug Fixes

- 修复 Windows release smoke 中 sidecar 子进程无法回传 `system.ready` 的超时问题。
- 修复桌面端发布产物校验无法识别新版 `agent-wiki` 技能指导的问题。

## 🔧 Maintenance

- 增加插件市场与 Wiki runtime 相关测试。
- 统一 sidecar 进程 RPC 的原始流分帧处理，减少 Windows 管道实现差异。
