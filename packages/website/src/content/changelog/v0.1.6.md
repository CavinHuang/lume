# Lume v0.1.6

> 重新设计桌面托盘与窗口行为，加入安全可控的中央 Wiki，并让文件引用、右侧工作区和自动更新更加可靠。

## 🔥 Highlights

- 🖥️ 托盘与窗口体验：托盘显示、最小化到托盘、关闭到托盘现在是三个清晰独立的设置；托盘可直接打开最近 5 条对话，Windows 与 macOS 分别保持符合平台习惯的行为。
- 📚 中央 Wiki：新增独立 Markdown 知识归宿，支持显式导入、Ask Wiki 只读问答、来源追踪和确认后写入，让长期知识不再散落在普通对话里。
- 📎 安全文件引用：消息中的 `@project` 与 `@session` 文件引用绑定到明确来源，预览、复制和跨会话使用时都会重新校验，减少路径变化造成的误读或越权。
- 🐛 更新真正生效：安装更新时由更新器完整接管退出与重启，阻止旧实例在文件替换前被再次启动。

## ✨ Features

- 托盘菜单新增“新建对话”“快速输入”和最近 5 条对话，可直接切换到目标会话；标题经过紧凑截断，菜单更易浏览。
- 窗口行为设置会即时同步到桌面主进程；关闭托盘后，两个依赖的托盘行为会同步关闭，避免无托盘状态下窗口消失。
- 新增中央 Wiki 的导入确认、访问控制、安全索引、中断恢复与可选 Obsidian 编辑流程。
- Agent 输出 Mermaid 图表时会遵循当前渲染器支持的语法，并支持技能文件热加载。
- 消息文件引用贯通消息展示、运行时上下文、右侧文件预览和桌面文件操作。

## 🐛 Bug Fixes

- 修复“重启更新”仅重新打开旧实例、没有实际安装新版本的问题；安装失败或更新器未能接管时会明确返回错误。
- 修复关闭或最小化窗口时，托盘设置与平台原生行为不一致的问题。
- 修复 macOS 菜单栏托盘图标显示为空白的问题，改为使用透明的 Lume Logo 并跟随系统明暗主题。
- 修复放大 Lume 窗口后右侧面板最大宽度过小的问题，现在按实际窗口宽度计算并保留合理留白。
- 为消息区与右侧面板补充分隔线，移除多余间距，仅保留可拖动的宽度分隔区域。
- 右侧面板移除尚未提供完整工作流的“审查”和“终端”入口，保留浏览器与文件能力。

## 🔒 Security

- Wiki 的读取能力仅在运行环境安全探针通过后开放，写入继续经过草案确认；探针失败时保持基础模式并拒绝扩大权限。
- Bash、Node REPL、插件命令、Hook 与本地 MCP 统一复用进程沙箱。
- 文件预览使用不可变引用与逐次权限复核，避免项目重绑、会话分叉或预览作用域变化造成静默越权。

## 🔧 Maintenance

- 统一侧栏交互样式并整理右侧工作区状态，旧的审查和终端持久化数据会被安全忽略。
- 补全 Wiki、统一输入区及托盘窗口行为的设计与审查记录，便于后续迭代保持既定边界。

## 🍎 macOS 安装说明

此版本没有 Apple Developer ID，安装包使用可验证的 ad-hoc 签名，因此首次启动不能直接双击：

1. 将 Lume 拖到“应用程序”，不要直接在安装镜像中启动。
2. 打开“应用程序”，按住 Control 点击 Lume，选择“打开”。
3. 在确认窗口中再次点击“打开”。
4. 如果仍被阻止，请前往“系统设置”→“隐私与安全性”，点击“仍要打开”。

Apple Silicon 设备请选择 `arm64` 安装包，Intel Mac 请选择 `x64` 安装包。
