# Lume v0.1.9

> 改进本地语义记忆恢复、Wiki 搜索降级和桌面端更新下载体验。

## 🔥 Highlights

- 🧠 本地 ONNX：初始化失败或请求超时后可以从设置页重新加载，不再需要重启应用恢复。
- 📚 Wiki 搜索：语义索引初始化受限时快速回退到词法搜索，并保持关键词结果准确过滤。
- ⬇️ 自动更新：下载进度使用真实累计字节数，更新器完成事件不会因平台返回值差异而悬挂。

## ✨ Features

- 在记忆设置中显示本地 ONNX 失败状态并提供重新加载操作。
- 增加本地 embedding 重置 IPC 通道与 sidecar runtime 状态恢复。
- Wiki 语义搜索增加超时保护，避免首次加载阻塞普通搜索。

## 🐛 Bug Fixes

- 修复本地 embedding worker 初始化失败后的 promise 与 listener 清理问题。
- 修复 Wiki 混合搜索在存在关键词时把所有可见页面重新带回结果的问题。
- 修复桌面更新下载进度回退、重复完成或累计字节数不准确的问题。

## 🔧 Maintenance

- 补充记忆设置状态与桌面更新进度的相关测试覆盖。
- 保持无新增依赖，复用现有桌面 API、sidecar RPC 和全局 UI 组件。
