# Lume v0.1.12

> 改进模型信息维护、上下文窗口配置、Wiki 搜索安全和工具结果展示。

## 🔥 Highlights

- 🤖 模型信息：Agent 设置页支持从 models.dev 同步模型能力、上下文长度和价格信息。
- 🧩 上下文窗口：模型元数据会参与 runtime-core 的上下文窗口解析，并保留工作区级覆盖配置。
- 🔒 Wiki 搜索：搜索结果返回受限页面引用，不再把完整页面正文带入搜索工具结果。
- 🛠️ 工具结果：grep 结果兼容字符串、stdout、output 和 matches 等返回形态。

## ✨ Features

- Agent 设置新增模型信息维护表格与手动同步按钮。
- 支持模型能力标签、价格信息和“未收录”状态展示。
- 补充模型元数据加载后的 runtime registry 刷新。

## 🐛 Bug Fixes

- 修复打包环境下本地 ONNX worker 仍引用 TypeScript worker 文件的问题。
- 修复 runtime-core fallback model 忽略模型元数据上下文窗口的问题。
- 修复 Wiki 搜索结果暴露完整页面记录的问题。
- 修复 grep 工具返回结构化数据时 UI 显示为 `[object Object]` 的问题。

## 🔧 Maintenance

- 增加模型元数据、通用设置、Wiki 搜索和 grep 展示测试覆盖。
- 复用现有模型元数据 IPC、设置持久化和 UI 原子组件，不引入新依赖。
