# Lume v0.1.0

> Lume 从对话助手迈向可持续协作的桌面智能体：它现在能理解并操作当前应用、组织项目文件、委派长期任务，并通过插件与多种模型扩展工作方式。

## 🔥 Highlights

- 🚀 原生 Computer Use: Lume 可以在 Windows 与 macOS 上理解当前窗口、读取界面并执行点击、输入、滚动和拖拽；操作前会展示目标与确认信息，敏感场景会主动停止。
- 🚀 持续协作的 Agent: 子代理支持独立会话、异步委派、任务报告与重启恢复，Todo 进度也会持久保存，较长任务不再因关闭应用或切换会话而丢失状态。
- 🚀 项目与文件工作区: 新的右侧文件工作区支持源码高亮、图片预览、项目目录与会话文件管理，让 Lume 能围绕真实项目文件持续工作。
- 🚀 更开放的能力入口: 新增插件市场、浏览器集成、图像生成、OpenAI Responses API 与 `node_repl`，可按任务组合所需能力。

## 🚀 Features

- feat(desktop,sidecar,web,shared): 新增跨平台 Computer Use，支持窗口感知、当前应用绑定、视觉上下文、原生鼠标键盘操作、应用发现与主动建议。
- feat(sidecar,web,sdk,shared): 子代理升级为可恢复的持续工作循环，支持异步委派、独立会话、绑定式 `TaskReport`、运行记录恢复和 Todo 状态持久化。
- feat(web,sidecar,desktop,shared): 重构文件工作区并引入项目工作目录，支持目录浏览、源码高亮、图片预览、文件附件及 Lume 文件上下文。
- feat(sidecar,web,sdk,shared): 完善插件市场，支持详情与 README 预览、安装权限审查、应用桥接、对话激活、手动更新和回滚。
- feat(sidecar,desktop,web): 整合浏览器插件与线程操作能力，网页凭证等敏感输入会进入安全中断流程。
- feat(sidecar,web): 新增图像生成工具，可选择兼容模型生成图片，并将结果保存到当前线程中直接预览。
- feat(desktop,sidecar,sdk): 新增线程级 `node_repl`，Agent 可以在隔离运行时中执行 JavaScript，并返回结构化文本或图片结果。
- feat(sidecar,web): 接入 OpenAI Responses API 模式，扩展可用模型与多轮工具调用方式。
- feat(desktop,web): 新增 `Alt+L` 快速输入窗口，可携带当前应用上下文快速发起对话。
- feat(web,shared,sidecar): 新增主题配色系统与多套调色板，并支持在对话中直接渲染 Mermaid 图表。
- feat(web): 输入框支持按会话恢复草稿、上下键回溯历史；会话列表自动更新时间，未读消息与长会话导航更清晰。
- feat(desktop,web,shared): 完善系统托盘、窗口控制和自动化入口，可从日程与运行记录直接跳转到任务详情或只读会话回放。
- feat(shared,web): 模型元数据支持从 models.dev 同步与手动更新，模型能力、上下文窗口和展示信息更准确。

## 🐛 Bug Fixes

- fix(desktop,sidecar,web,shared): 强化桌面操作边界——锁屏或挂起时暂停感知，敏感选区不进入上下文，执行前后重新校验目标，避免操作落到错误应用。
- fix(desktop,sidecar): 修复 Windows 截图色彩、坐标换算、定向输入与更新安装文件占用问题，并稳定 macOS 授权、窗口捕获和复杂控件点击。
- fix(web): 修复长会话中的历史丢失、重复消息、滚动跳动、Todo 面板闪烁，以及压缩后消息标识冲突等问题。
- fix(sidecar,sdk): 修复 OpenAI Responses 多轮工具调用、会话恢复缺失结果、Todo 会话串台和工具结果为空时的上下文问题。
- fix(sdk): WebFetch 改进正文抽取与图片处理，支持渲染 SPA 页面，并加强资源下载、导航与图片沙箱校验。
- fix(sidecar,web): 修复插件安装状态、市场来源、详情页状态和桥接路径校验，降低安装与更新失败概率。
- fix(sidecar): 修复自动化任务的重复执行与跳过循环，并用单例守卫避免多个 sidecar 同时运行同一任务。
- fix(desktop): 修复托盘图标、任务栏图标、文件协议路径和打包资源问题，提升开发与正式构建的一致性。

## ⚡ Performance

- perf(web): 优化流式消息平滑、定时器隔离与派生状态缓存，长回复结束更自然，其他会话和侧栏不再被频繁重绘拖慢。
- perf(web): 增加按会话 LRU 消息缓存与稳定事件投影，切换会话时减少空白和重复加载。
- perf(sidecar,desktop): 桌面上下文改为事件驱动并复用线程级会话，减少重复探测与进程间通信开销。

## 🔧 Maintenance

- 内部: 完成 Electron 原生能力切换，统一 Computer Use、插件、模型元数据与 Agent 运行时契约；补充跨平台验收、回归测试及设计文档，并清理已废弃实现。
