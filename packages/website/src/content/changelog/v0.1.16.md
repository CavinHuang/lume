# Lume v0.1.16

> 让编码任务更容易验证、恢复和继续，同时把能力选择与权限确认变得更清晰。

## 🔥 Highlights

- 🧪 编码任务验证：修改完成后可以自动检查结果并把失败反馈回同一任务，减少“看似完成但未验证”的情况。
- 🧭 能力路由：根据用户意图更准确地选择 coding、browser、memory、web、skills 或 raw-tools 能力，降低无关工具干扰。
- 🛡️ 权限交互：询问用户和工具授权统一为更清晰的决策界面，敏感操作的授权范围与状态更容易理解。

## 🚀 Features

- sidecar：完善 coding run 的状态追踪、验证闭环、后台任务等待和单次自动修复，长任务可以更可靠地继续执行。
- sidecar：增强能力路由与工具执行网关，让 skill、工具描述、计划模式和权限规则保持一致。
- web：重做 Ask User、Permission 和浏览器交互面板，展示更完整的决策上下文和授权结果。
- sdk：完善完成约束、上下文运行元数据、PowerShell Shell 执行和结构化运行事件，主机可以更准确地控制任务结束条件。

## 🐛 Bug Fixes

- 修复工具权限确认在不同入口下状态不一致的问题，并保留高风险操作的硬拒绝边界。
- 修复下拉菜单组件无法安全转发 ref 的问题，避免交互层组合组件时丢失底层菜单引用。
- 修复后台工具输出、任务恢复和并行工具结果在运行事件中的上下文信息不完整问题。

## 🔧 Maintenance

- 补充 coding run、工具执行网关、能力路由、权限交互和 SDK 引擎测试覆盖。
- 复用现有 shadcn/global UI 组件与权限运行时，不引入新的第三方依赖。
