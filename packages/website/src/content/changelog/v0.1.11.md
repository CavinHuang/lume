# Lume v0.1.11

> 修复本地 ONNX 运行时打包与 Windows sidecar smoke，并增加消息列表布局选项。

## 🔥 Highlights

- 🧠 本地 ONNX：将 worker、ONNX Runtime native binding 和 sharp native binding 纳入桌面资源验证，避免安装包运行时缺失原生模块。
- 🛡️ Windows 发布：增强 sidecar bundle smoke 与产物输入校验，覆盖真实安装包启动链路所需的全部资源。
- 💬 消息列表：外观设置新增气泡模式和文档模式，支持将用户消息统一左对齐展示。

## ✨ Features

- 新增消息列表排列方式的持久化设置与类型校验。
- 文档模式下用户消息与助手消息统一从左侧开始，保留附件、编辑和交互能力。
- sidecar bundle 构建时复制平台对应的 ONNX Runtime 与 sharp 原生文件。

## 🐛 Bug Fixes

- 修复打包后的 sidecar 无法定位编译后的本地 ONNX worker 的问题。
- 修复桌面安装包缺少 `resources/bin` 原生资源目录的问题。
- 修复发布前校验未覆盖本地 ONNX worker 和 native binding 的问题。

## 🔧 Maintenance

- 扩展 sidecar bundle、桌面产物输入和产物归档校验。
- 增加通用设置持久化与消息列表状态测试覆盖。
- 保持无新增依赖，复用现有 Electron resources、sidecar RPC 和全局 UI 组件。
