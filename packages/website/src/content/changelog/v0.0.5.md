# Lume v0.0.5

> 模型设置体系整合：所有模型配置统一入口，新增自动化任务专用模型；修复自动化任务失败却误显示成功。

## 🔥 Highlights

- 🚀 模型设置统一入口: 读书/记忆/默认对话/自动化任务的模型配置全部收敛到「设置 → 模型 → 模型设置」，不再散落各处。
- 🚀 自动化任务专用模型: 新增「自动化任务」模型配置，定时任务可用独立模型，与日程调度、默认对话解耦。
- 🐛 自动化任务状态修复: 任务执行失败时不再误显示为「成功」，能正确反映失败并展示错误信息。
- 🐛 Windows 安全修复: 修复 PowerShell 命令注入漏洞。

## 🚀 Features

- feat(web): 模型配置入口统一收敛到「模型设置」页，读书/记忆页移除重复模型区块
- feat(web,sidecar): 新增「自动化任务」模型配置（models.automation），定时任务按来源分流使用
- feat(web,sidecar): 模型动作设置按用途分组（主力 / 轻量后台 / 记忆 / Embedding 等）
- feat(agent): 欢迎页建议与会话标题生成接入专用模型
- feat(web): 欢迎页无 AI 建议时显示默认建议兜底
- feat(web): 版本更新支持从 GitHub Release 拉取资产
- feat(desktop): 自动更新签名公钥支持环境变量配置
- feat(automation): 区分手动与系统自动化任务来源
- feat(web): 技能/插件市场页头与切换 UI 调整

## 🐛 Bug Fixes

- fix(routine): 自动化任务执行失败时正确标记为「失败」，不再误显示成功
- fix(sdk): 修复 Windows PowerShell 命令注入漏洞（-NoProfile）

## 🔧 Maintenance

- style(web): 优化 agent 消息区滚动条样式
- docs(web): 记录模型动作设置设计文档
