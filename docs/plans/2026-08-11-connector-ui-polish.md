# 连接器界面优化计划

## 目标

在不改动 Link 运行时、IPC 与共享数据结构的前提下，让连接器页面对齐 `wanta` 的信息架构，并修正 SaaS 品牌 Logo 的展示。

## 范围

1. 将目录页改为「紧凑目录 + 右侧详情」双栏，连接账户收进详情面板。
2. 复用现有 Button、Dialog、Input、Tabs 等全局 UI 原子组件；只补缺失的通用搜索/筛选原语。
3. 把授权表单从主页面拆出，保留现有 OAuth、密钥保存、断开连接行为。
4. 品牌图标按本地社区图标、服务端 `iconUrl`、字母占位依次兜底；不依赖网络 CDN。
5. 删除主页面中的运行记录展示，仅删除 UI 入口，不改底层运行记录 API。

## 验证

- 连接器组件与图标解析相关测试通过。
- Web 构建通过，确认拆分后没有类型或导入错误。
- 人工检查目录、搜索筛选、详情、连接/重连/断开以及空状态在常见宽度下的布局。

## 约束与风险

- 品牌 Logo 仍受各品牌商标规范约束；社区图标包只解决资产维护与覆盖率。
- 本次不修改后端能力，目录返回的数据缺失时继续显示稳定的字母占位。
- 不新增与界面无关的抽象，不顺手清理连接器外部代码。
