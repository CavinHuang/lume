# 连接器界面优化计划

## 目标

让连接器页面对齐 `wanta` 的信息架构，修正 SaaS 品牌 Logo 的展示，并让同一界面可安全连接本机或已有 OpenConnector 部署。

## 范围

1. 将目录页改为「紧凑目录 + 右侧详情」双栏，连接账户收进详情面板。
2. 复用现有 Button、Dialog、Input、Tabs 等全局 UI 原子组件；只补缺失的通用搜索/筛选原语。
3. 把授权表单从主页面拆出，保留现有 OAuth、密钥保存、断开连接行为。
4. 品牌图标按 theSVG 社区目录、本地 Lobe/Simple Icons、字母占位依次兜底。
5. 删除主页面中的运行记录展示，仅删除 UI 入口，不改底层运行记录 API。
6. 扩展 Link 运行时配置，支持 HTTPS（或 loopback HTTP）的已有部署；远程凭据继续由桌面端加密保存并按 origin 隔离。

## 验证

- 连接器组件与图标解析相关测试通过。
- Web 构建通过，确认拆分后没有类型或导入错误。
- 人工检查目录、搜索筛选、详情、连接/重连/断开以及空状态在常见宽度下的布局。

## 二次视觉对齐

初版拆分完成后，实际开发窗口仍暴露出三个差距：目录 Logo 只有 20px 且没有品牌图标容器；未选中连接器时目录被额外包在大卡片中，层级比参考项目更重；添加连接弹窗把字段平铺展示，没有区分连接身份、认证配置和 OAuth 等待状态。

本轮按 `wanta` 的现有组件结构做以下收敛：

1. 目录改为页面级 split view：工具栏与内容直接占满可用区域，选中后只增加右侧带左分隔线的详情栏。
2. 列表卡片保持 68px，但 Logo 使用 36px 有边框图标容器、内部 24px 品牌图形，并补充可读的状态标签。
3. 详情头、连接区、账户列表和提供方信息分段展示；认证方式在连接区中作为可见能力呈现。
4. 添加连接弹窗按「连接身份 / 认证配置 / OAuth 回调与授权状态」分组，等待授权时显示明确进度与重新打开入口。
5. 展示与交互组织保持既有 Link IPC 语义；远程运行时仅扩展启动配置与凭据保存边界。

## 约束与风险

- 品牌 Logo 仍受各品牌商标规范约束；theSVG CDN 不可用时会自动回退本地图标。
- 不修改 OpenConnector 的业务能力，目录返回的数据缺失时继续显示稳定的字母占位。
- OAuth 待授权状态必须绑定发起时的运行时 origin，切换部署后不得恢复或轮询旧部署会话。
- 不新增与界面无关的抽象，不顺手清理连接器外部代码。
