# Lume v0.1.5

> 新增全链路诊断与更安全的日志能力，优化模型上下文缓存，并修复桌面更新与读书笔记显示问题。

## 🔥 Highlights

- 🔎 全链路诊断: 日志页支持实时查看、组合筛选、导出与 trace 关联，排查消息、模型调用、工具执行和回复投递问题更直接。
- ⚡️ 上下文缓存: 将稳定提示词与运行时上下文分离，并为 OpenAI、Anthropic、OpenRouter、DeepSeek 等 provider 应用对应缓存策略，减少重复输入处理。
- 🐛 更新更可靠: “重启并更新”改为静默安装并由更新器统一重启，不再同时拉起旧应用和安装界面。
- 📖 阅读体验: 读书笔记现在按 Markdown 渲染，标题、列表、引用和代码等排版采用更紧凑的小字号样式。

## ✨ Features

- 桌面端统一接管主进程、Sidecar 与渲染进程日志写入，提供轮转、保留、查询、实时跟随、清理和导出能力。
- Agent 消息链路加入 trace 关联，可串联请求接收、模型响应、工具和子 Agent 执行、消息持久化及渲染确认。
- 日志设置支持按级别、来源、事件、状态和 trace 筛选，并可查看慢请求与失败节点。
- 增加限时、限定线程或 trace 的诊断正文捕获；内容使用系统安全存储加密，到期自动失效并可随时清除。
- 模型工具名在不同 provider 之间统一规范化，降低工具调用格式差异导致的失败。

## 🐛 Bug Fixes

- 修复点击“重启并更新”后旧应用与安装界面同时启动的问题。
- 修复临时子 Agent 缺少独立线程元数据时无法继承投递线程工作目录的问题。
- 修复多个设置入口并发写入时可能相互覆盖的问题，统一由桌面主进程串行持久化。

## ⚡️ Performance

- 稳定系统提示词与动态运行时上下文分段发送，提升 provider 提示词缓存命中机会。
- 低价值高频 RPC 默认降噪，仅突出慢请求、失败和关键链路事件，减少日志写入与排查干扰。

## 🔧 Maintenance

- 移除旧的 Rust 日志库、`electron-log` 与 Sidecar 日志查看服务，收敛为单一桌面日志实现。
- 保留旧日志读取兼容，不要求用户迁移已有日志文件。
