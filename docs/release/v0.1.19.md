# Lume v0.1.19

> 让编码审查、任务输入和后台工具执行衔接得更顺畅。

## 🔥 Highlights

- 🔎 编码审查：变更文件、行数和恢复操作展示更完整，查看任务结果时更容易确认实际影响。
- ✍️ 任务输入：发送、排队和计划模式切换反馈更及时，长任务中继续追加指令更可靠。
- ⚙️ 后台工具：Shell 后台任务和文件写入增加并发协调，减少重复执行或相互覆盖。

## 🚀 Features

- sidecar：完善编码变更追踪、运行事件和验证状态，让任务完成前的审查信息更加准确。
- web：优化 Coding Review 面板、Agent 输入区、侧边栏和欢迎页的任务入口与状态展示。
- sdk：增强后台进程生命周期管理、Shell 输出恢复和文件变更锁，提升工具执行的连续性。

## 🐛 Bug Fixes

- 修复编码变更统计、恢复入口和历史运行报告在部分状态下信息不完整的问题。
- 修复后台任务输出、文件写入和任务输入状态在快速连续操作时可能不同步的问题。

## 🔧 Maintenance

- 补充编码审查、任务输入和 Shell 工具测试覆盖，复用现有实现并保持零新增第三方依赖。
