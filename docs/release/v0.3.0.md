# Lume v0.3.0 — 浏览、编码与任务执行全面加固

> 这次更新让 Lume 的桌面 Agent 更适合长时间、跨工具工作：浏览器会话能够连续使用，任务进度更清晰，文件与编码上下文更容易交给 Agent，同时补强了权限、路径和运行时边界。

## ✨ 这次更新，一眼看懂

| 能力 | 你会感受到的变化 |
|---|---|
| 🌐 **连续的浏览器任务** | 内置浏览器可以保留登录状态、导入已连接 Chrome 的 Cookie，并在多轮对话中继续操作同一个页面 |
| 🧰 **更会找工具的 Agent** | Agent 会按任务动态发现技能与工具，等待授权或提问后也能从中断处继续执行 |
| 📡 **更稳定的任务进度** | 工具执行、后台任务、上下文整理和终止状态通过统一事件链展示，减少重复卡片、空消息和状态丢失 |
| 📁 **更顺手的文件工作台** | 可在欢迎页 `@` 项目文件、附加外部目录、将引用文件晋升到项目，并获得更清晰的来源与预览体验 |

## 🔥 Highlights

### 🌐 浏览器操作可以跨轮连续完成

内置浏览器现在更像一个可持续使用的工作空间，而不是一次性页面。Agent 能继续操作已经打开的标签页，并在需要登录时保留你的会话状态。

- **浏览器（desktop / sidecar / web）**：支持从已连接的 Chrome 导入 Cookie，持久化内置浏览器登录状态，并修复刷新、代理环境、登录弹窗和路由恢复问题。
- **浏览器（desktop / sidecar）**：补齐等待、对话框、剪贴板、frame 与自动等待能力，页面操作失败时会给出更准确的错误类型。
- **浏览器（desktop）**：截图和页面定位采用更紧凑的上下文，长页面任务更不容易因内容过多而中断。

### 🧰 Agent 会按需发现工具，并能从中断处恢复

工具不再需要一次性全部塞进上下文。Lume 会根据当前任务和已启用技能动态提供相关能力，让 Agent 更容易找到正确工具，也减少无关信息占用。

- **工具系统（sdk / sidecar）**：支持技能目录注入、动态工具发现与晋升，以及沙箱内的工具调用桥接。
- **任务执行（sdk / sidecar / web / desktop / shared）**：授权、提问或其他中断结束后，Agent 可以在原任务中继续，而不是丢失进度后重新开始。
- **子代理（sdk / sidecar）**：子代理继承父任务的目录和权限边界，后台工作与主任务的衔接更稳定。

### 📡 长任务的过程更清楚、更可靠

任务状态、工具调用、后台通知和上下文整理统一进入新的事件链。界面会更及时地显示正在发生什么，重载或恢复会话时也更不容易出现重复内容。

- **任务界面（web）**：新增任务进度行、工具执行计时与渐进状态，并优化建议卡片、审批卡片、上下文卡片和注意事项的呈现。
- **会话运行时（sidecar / sdk / shared / web）**：统一处理流式消息、工具开始与结束、后台任务、上下文压缩和失败终态。
- **可靠性（web / sidecar）**：修复重复工具卡、流式正文丢失、终态后重复消息、后台失败无反馈，以及运行事件长期占用内存的问题。

### 📁 文件与编码上下文更容易交给 Agent

- **文件工作台（web / sidecar / shared）**：欢迎页支持 `@` 选择项目文件；外部目录可以附加为迷你文件树，引用文件可直接晋升到项目目录。
- **文件预览（web）**：增加来源标识、源码视图与自动换行，修复拖拽冻结、超大 HTML 预览和预览状态异常。
- **编码任务（sidecar）**：大型仓库快照改为轻量扫描，减少首次运行卡顿；配置为自动启动的 LSP 会在任务开始时后台预热。

## 🚀 Features

- **外观与阅读（web / shared / sidecar）**：加入 MiSans 与 JetBrains Mono，提供对话字号档位，并重新设计正文宽度、标题层级和阅读页排版。
- **记忆（sidecar / web）**：记忆编辑草稿不会再被后台刷新覆盖，旧版短记忆可继续迁移使用，后台整理后的变更会及时反映到界面。
- **文件改动（web）**：改动文件以更紧凑的 chip 展示，并通过渐进动画帮助快速识别本轮任务产生的结果。
- **模型与会话（web）**：模型列表显示对应供应商，右侧面板状态按会话保存，长列表的浏览体验更稳定。

## 🐛 Bug Fixes

- **桌面运行时（desktop / sidecar）**：修复 sidecar 启动失败后的错误重启、Link 重启竞态、旧进程状态污染，以及发布包遗漏 OpenConnector 资源的问题。
- **浏览器工作区（desktop / web）**：清理失效标签页与孤儿截图，避免历史数据持续累积；修复同页导航、调试订阅和多轮页面恢复问题。
- **Office 工具（sidecar）**：修复批注 XML 转义、转换产物命名、自动修复未接线和占位工具生成假产物等问题。
- **会话与记忆（web / sidecar）**：修复删除线程后缓存残留、运行中会话被误清理、记忆整理产生幽灵消息，以及工作模式建议重复生成。
- **跨平台兼容（sdk / sidecar / web）**：移除部分 Bun 专属读取方式，修复 YouTube、docs.rs、GitLab 内容抓取和 Windows 路径处理问题。

## 🔒 Security

- **桌面与文件（desktop / web）**：收紧 renderer 可访问的文件与 IPC 通道，外部链接统一校验协议，Mermaid SVG 和 HTML 预览增加第二层防护。
- **网络与浏览器（sidecar / sdk）**：统一私网地址判定，Web Fetch 会校验真实目标地址，避免代理或特殊 IP 表示绕过限制。
- **工具与插件（sdk / sidecar）**：限制插件、MCP 子进程和 LSP 可继承的环境与路径；工作树进入、退出和文件编辑都需位于允许边界内。
- **授权与子代理（sdk / sidecar）**：用户回答只接受宿主注入通道，子代理与工具调用不能扩大父任务已有权限。

## ⚡ Performance & Reliability

- **大型仓库（sidecar）**：编码快照改用 Git 枚举与轻量元数据扫描，显著减少大型项目首次运行的等待与状态文件体积。
- **长会话（sidecar / web）**：消息记录改为增量追加，运行轨迹与线程索引加入缓存，降低长时间任务中的重复解析和磁盘读取。
- **任务界面（web）**：消息内容使用延迟渲染，minimap 和状态派生减少流式更新期间的全量重算。
- **后台服务（sidecar）**：Wiki、记忆、配置与事件读取增加合适的缓存和节流，同时保留文件监听带来的即时更新。

## 🔧 Maintenance

- **内部维护（desktop / sidecar / sdk / shared / web）**：清理无调用入口的旧界面、CLI、阅读控制面、插件管理器与生成快照，合并重复运行时实现，并补齐关键回归测试；这些调整不需要用户操作。

## ⬆️ 升级说明

- 本版本没有需要手动迁移的破坏性变更。
- 已有浏览器、会话、记忆和项目数据会沿用；旧版短记忆在首次使用时自动兼容处理。
- 浏览器 Cookie 导入只复制所选来源的登录信息，不会修改原 Chrome 配置。
