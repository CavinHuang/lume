# Lume v0.0.2

> 这个版本修复桌面安装包的启动观感和品牌图标，让 Windows 与 macOS 的安装体验更像一个完整的桌面应用。

## 🔥 Highlights

- 🐛 Windows 启动更安静：修复 Windows 发布包启动时额外弹出 cmd 窗口的问题，打开 Lume 时只显示应用本身。
- 🐛 桌面图标恢复正确：macOS 和 Windows 的应用图标重新使用 Lume 彩色 logo，并统一为白底圆角桌面图标。
- 🐛 Windows 安装包缩略图：NSIS 安装器现在使用同一份 Lume 图标，下载后的安装包在资源管理器里更容易识别。

## 🐛 Bug Fixes

- fix(desktop): Windows 发布包隐藏随包 sidecar 的控制台窗口，避免用户启动应用时看到额外 cmd 窗口。
- fix(desktop): 重新生成 macOS `.icns`、Windows `.ico` 和通用 `.png` 图标，安装后应用图标保持一致。
- fix(desktop): Windows NSIS 安装器使用 Lume 图标作为安装包缩略图。
