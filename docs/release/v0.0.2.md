# Lume v0.0.2

> 修复 Windows 桌面端侧载进程启动失败的问题。

## 🐛 Bug Fixes

- **Windows 启动崩溃**: 修复了在 Windows 上 sidecar 进程启动时 `realpathSync('D:')` 导致 `EISDIR` 错误的问题。现在 Windows 用户可以正常连接后端并使用应用。

## 📝 说明

v0.0.2 是一个紧急补丁版本，仅包含一个关键修复。如果你在 Windows 上使用 v0.0.1 时遇到"无法连接后端"的问题，请升级到 v0.0.2。
