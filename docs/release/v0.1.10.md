# Lume v0.1.10

> 优化本地 ONNX 模型的首次下载入口与记忆设置反馈。

## 🔥 Highlights

- 🧠 本地 ONNX：模型未缓存时，记忆设置页直接提供“下载模型”入口。
- 🧭 状态反馈：下载中的按钮文案与模型状态提示保持一致，用户无需触发语义召回才开始下载。
- ✅ 行为校准：同步更新 sidecar 状态说明和测试断言，避免 UI 与 runtime 提示不一致。

## ✨ Features

- 在本地 ONNX 模型未缓存或初始化失败时显示可操作按钮。
- 复用现有本地 embedding reload IPC 和设置页动作状态，不引入新的依赖或下载链路。

## 🐛 Bug Fixes

- 修复首次使用本地语义召回前缺少明确下载操作入口的问题。
- 修复本地 ONNX 未缓存状态提示仍描述为“首次使用自动下载”的过时文案。

## 🔧 Maintenance

- 更新 memory settings snapshot 测试，覆盖新的下载提示。
