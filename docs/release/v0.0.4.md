# Lume v0.0.4

> 本版本是 macOS 安装版热修，解决 v0.0.3 安装后无法打开的问题。

## 🔥 Highlights

- 🐛 macOS 启动修复: 修正桌面应用图标资源格式，安装版不再因为托盘图标初始化失败而崩溃。

## 🐛 Bug Fixes

- fix(desktop): 修复 macOS 安装版启动崩溃。v0.0.3 的图标资源使用了 Tauri 托盘不接受的 16-bit RGBA PNG，本版本重新生成 8-bit 图标资源。

## 🔧 Maintenance

- 增加桌面打包输入检查，阻止 16-bit PNG 图标再次进入发布包。
