# Lume v0.1.20

> 浏览器自动化、Coding Review 和工作区文件操作迎来一轮完整升级。

## 🔥 Highlights

- 🌐 浏览器工作区：支持更完整的浏览器标签、页面控制和安全隔离，Agent 与用户浏览环境保持清晰边界。
- 🔎 Coding Review：提供 Pierre 风格 diff、行级评论和更丰富的变更审查体验，代码修改更容易核对与反馈。
- 📁 文件工作区：文件树、编辑器、HTML/PDB/MCP 资源预览和草稿保存统一到右侧工作区，查看与修改文件更连贯。
- 🛡️ 安全边界：加强 IPC、预览协议、浏览器网络、凭据和文件引用校验，降低跨上下文访问风险。

## 🚀 Features

- desktop：新增浏览器运行时、覆盖层和安全预加载桥接，支持用户、Agent 与高级调试会话隔离。
- sidecar：完善浏览器 broker、外部 Chrome 传输、文件选区编辑、MCP 资源和运行事件协议。
- web：重构 Coding Review 与右侧工作区，支持 diff 行评论、文件编辑草稿、多种资源预览和浏览器标签管理。
- sdk/shared：补强 LSP 多服务器、进程作业续接、文件引用和浏览器运行时类型协议。

## 🔧 Maintenance

- 补充浏览器安全策略、文件操作、运行事件、MCP、diff 和右侧工作区测试覆盖。
- 复用现有权限、RPC、文件引用和预览边界实现，保持发布链路可验证。
