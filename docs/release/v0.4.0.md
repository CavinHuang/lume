# Lume v0.4.0

> 日志系统重设计落地：内容字段不再整段遮蔽而是截断预览、开发模式控制台输出全量链路；并修复嵌套凭据可能漏脱敏的安全问题。

## 🔥 Highlights

- 📋 **日志内容字段改为截断预览**: `body` / `prompt` / `content` 等内容类字段在日志中由原来的 `[redacted]` 整段遮蔽，改为保留前 200 字符的截断预览——排查问题时能直接看到关键上下文。**注意**：升级后同一份日志文件里会新旧两种形态混排，这是正常现象不是日志损坏。凭据类字段（token / password / apikey 等）仍然完全遮蔽不受影响。
- 🔍 **开发模式控制台默认输出全量链路**: 开发构建（非打包版）的控制台日志默认放开到 trace 级别，启动即可看到 agent 执行链路与 IPC/RPC 往返全程；在设置中显式改过日志级别的话以你的设置为准。

## 🔒 Security

- 嵌套凭据脱敏绕过修复: 此前藏在嵌套对象里的凭据类字段（如深层结构中的 token）可能在部分摘要路径下未被遮蔽就落入日志；现在任意嵌套层级一律 `[redacted]`。
