# Lume v0.1.13

> 改进桌面端更新下载、安装过渡和跨平台更新体验。

## 🔥 Highlights

- ⬇️ macOS 更新：支持在应用内下载 GitHub DMG 更新包，显示实时进度并交给主进程安全安装重启。
- 🪟 Windows 更新：显示安装器进度，避免静默退出造成的空白等待，同时在安装完成后自动启动新版本。
- 🛡️ 更新安全：限制应用内 DMG 下载地址为 HTTPS GitHub release asset，安装动作继续通过受信任 IPC 执行。

## ✨ Features

- 新增桌面端更新资产下载与安装 bridge API。
- 更新设置页新增安装过渡层，明确展示下载完成、退出替换和重新启动状态。
- 下载进度统一展示累计字节数、总大小和百分比。

## 🐛 Bug Fixes

- 修复 macOS 仅能打开外部下载安装包、无法在应用内完成更新的问题。
- 修复 Windows 自动更新静默安装期间用户看不到进度的问题。
- 修复更新安装过程中的 renderer IPC pending 生命周期与重启协调问题。

## 🔧 Maintenance

- 增加桌面更新安装行为的 package-level 测试覆盖。
- 复用现有 updater、受信任 IPC 和下载进度事件，不引入新依赖。
