# Lume v0.0.3

> 再次修复 Windows 桌面端 sidecar 启动崩溃问题。

## 🐛 Bug Fixes

- **Windows 启动崩溃 (v0.0.3)**: 修复 `normalize_windows_path` 未能覆盖所有 `\\?\` 路径来源的问题。现在桥接进程的 cwd 被正确规范化，Node.js `realpathSync` 不会再对裸盘符 `D:` 调用 `lstat` 导致 `EISDIR` 崩溃。

## 📝 说明

v0.0.3 是 v0.0.2 的跟进修复。如果你在 Windows 上使用 v0.0.2 仍然遇到"无法连接后端"，请升级到 v0.0.3。
