# Lume v0.3.1

> 聚焦编码能力与权限边界的加固:思考档位真正生效、项目指令自动注入、编辑先读强制与 PowerShell 审批收紧。部分行为与上一版本不同,升级前请阅读下方说明。

## 🔥 Highlights

- 🧠 **思考档位生效**:设置中的思考档位(关闭 / 低 / 中 / 高 / 最大)现在会真实作用于模型请求;此前各档预算在链路上被坍缩为固定 medium。
- 📄 **更高的单轮输出上限**:使用内置目录模型时,单轮输出上限从固定 16384 tokens 提升为模型的真实上限(如 32768 或更高),长回答与大型代码生成更少被截断。
- 📋 **项目指令自动注入**:Agent 会自动读取项目目录的 `CLAUDE.md` / `AGENTS.md` 并注入系统提示——就近向上解析(至 git 根或主目录为止),单文件超过 32KB 时截断;会话头部会显示当前生效的指令文件,可在权限设置中关闭。
- ✏️ **编辑前必须先读**:直接修改未读过的文件现在会被拦截并给出明确错误提示,而不是盲目写入——避免覆盖你尚未查看的内容。
- 🪟 **Windows PowerShell 审批更严格**:PowerShell 命令引入双重审批闸门,更多命令会弹出确认框。这是刻意的安全收紧,不是故障。

## ⚠️ 行为变化说明

| 变化 | 之前 | 现在 |
|---|---|---|
| 思考档位 | UI 档位不改变实际出网请求 | 档位按模型能力映射为思考预算下发 |
| 单轮输出 | 固定 16384 tokens | 目录模型取真实输出上限 |
| 项目指令 | 不加载 CLAUDE.md/AGENTS.md | 自动加载并注入(就近向上查找,32KB 截断) |
| 未读文件编辑 | 可直接盲改 | 返回明确错误,要求先 Read |
| Windows PS 命令 | 部分命令免审直接执行 | 双闸校验,审批弹窗增多 |

## 🐛 Bug Fixes

- 修复思考预算配置整链失效的问题(档位坍缩、自适应思考元数据丢失)。
- 修复编辑防护错位导致的未读可盲改、跨轮失忆问题。
- 修复只读命令免审通道缺失带来的高频审批打扰(PowerShell 除外,见上)。
