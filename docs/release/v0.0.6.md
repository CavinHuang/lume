# Lume v0.0.6

> 新增 /compact、/clear 两个会话命令，并完成一轮系统性的流式渲染与后端存储性能优化——长会话更流畅、打开会话更快。

## 🔥 Highlights

- 🚀 会话命令 /compact 与 /clear: 输入 `/` 即可呼出命令菜单，选中即执行。`/compact` 压缩当前会话上下文（完成后可展开查看 LLM 生成的总结）；`/clear` 清空当前会话消息（保留线程，带二次确认防误触）。
- ⚡ 流式渲染与多会话性能: 消息列表改增量投影、rAF 批量合并流式事件、按会话隔离重渲染——流式输出更跟手，一个会话的流式不再拖动侧栏与其他会话。
- ⚡ 打开会话更轻量: 打开会话时的数据载荷大幅裁剪，启动更快、内存占用更低。
- 🐛 桌面端界面修复: 消息气泡中的长英文串（URL/路径/长词）现在能正常换行；修复 Windows 端窗口顶部多余空白。

## 🚀 Features

- feat(web,sidecar): 新增 `/compact` 命令——压缩当前会话上下文，完成后可展开查看 LLM 生成的总结
- feat(web,sidecar): 新增 `/clear` 命令——清空当前会话消息（保留线程），带二次确认防误触

## ⚡ Performance

本轮系统性的渲染与存储优化（性能路线图 Phase 1–6），主要用户可感知的提升：

- 流式渲染: 消息列表增量投影 + rAF 批量合并流式事件 + 限流 Markdown 重解析，流式输出更流畅
- 多会话隔离: 按会话(threadId)切片订阅，跨线程 re-render 隔离，侧栏与其他会话不再被某个会话的流式拖动
- 打开会话: 打开会话 payload 裁剪（去掉全量 sdkMessages），启动更快、更省内存
- 本地记忆: embedding 批量化（N 次 IPC 合并为 1 次）+ 向量召回改 Float32 dotProduct，记忆检索更快
- 后端存储: trace / run-state 改 append-only、markdown 按文件名定位，消除写放大与全库解析
