# Lume v0.1.21

> 输入队列、浏览器批注与主动 Agent 三件套齐上线 —— Agent 更懂你的习惯，也更听你的指挥。

## 🔥 Highlights

- 🧩 **输入队列与软中断**：Agent 运行时可以连续排队消息，并支持暂停 / 恢复（软中断），不再需要为插一句话而强行终止整个会话。
- 💬 **浏览器批注**：在内置浏览器网页上直接给元素留批注，批注作为上下文交给 Agent，Agent 能看到、能回应，还能把批注内容直接作为提交消息。
- ✨ **主动 Agent**：基于完整用户画像（L3 Persona）在合适时机主动给出建议，并按你的工作模式自动触发分析 —— 从「被动回答」走向「主动协作」。
- 🎨 **网页内设计编辑 + 浏览器基建升级**：design-editor 让你直接在网页里编辑设计元素；内置浏览器改用 webview guest 池更稳定，Native Host 也改为自动安装。

## 🚀 Features

**输入队列与中断控制（对齐 Codex）**
- Agent 运行中可排队后续消息，支持 blocked 重试、富引导与三态（立即 / 排队 / 阻塞）路由配置。
- 新增软中断：可暂停运行中的 Agent 并从断点恢复，无需终止会话。
- 输入框支持拖拽附件预览、平铺展示与重新排序。

**浏览器批注（对齐 Codex）**
- 在内置浏览器网页上为元素添加批注，Agent 接收批注作为上下文附件。
- 宿主面板统一查看批注 / 评论列表，支持 resolve 与标记已读。
- 批注正文可直接作为提交消息内容。

**网页内 design-editor（对齐 Codex）**
- 在浏览器网页内直接编辑设计元素，支持多选、锁定与 scrub 精细调整。

**主动 Agent（三周期）**
- 主动建议：Agent 在合适时机主动给出操作建议。
- L3 Persona：构建完整用户画像，让建议贴合个人习惯。
- 主动中心自动化：按工作模式自动触发分析。

**内置浏览器 shell**
- 内置浏览器改用 webview guest 池，多标签更稳定。
- 浏览器授权走 broker 路由与 reference-grant，安全隔离更清晰。

**Native Host 自动安装**
- 插件 Native Host 现在自动安装，无需手动配置。

**Agent 输入与执行**
- `@mention` 文件引用重做，支持文件拖拽引用。
- 规划与日程可持久化保存。
- 停止 Agent 现在真正中止运行中的执行。
