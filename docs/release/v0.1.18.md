# Lume v0.1.18

> 让长任务的状态反馈更连贯，让文件与命令工具在边界场景下更可靠。

## 🔥 Highlights

- 🧭 运行状态：任务完成、失败和继续执行时的状态与运行事件保持一致，减少界面显示滞后或重复。
- 💬 Agent 消息：工具结果、任务进度和编码变更反馈更稳定，长任务过程更容易理解和追踪。
- 🛡️ 工具安全：文件路径、Shell 命令和工具审批边界得到加强，降低误操作和越界访问风险。

## 🚀 Features

- sidecar：完善 coding run 的终态收敛、运行事件投影和隔离 worktree 工具暴露策略。
- web：改进运行事件消息、工具结果和编码报告展示，历史任务也能补充可用的变更信息。
- sdk：增强 Agent/Engine 工具发现与审批流程，并改进 Bash、Read、Edit、Write 和 worktree 工具的执行反馈。

## 🐛 Bug Fixes

- 修复运行事件在多轮任务和子代理场景下可能出现的状态、文本或工具反馈不一致。
- 修复文件工具处理路径、编码、行范围和外部修改时的边界问题。

## 🔧 Maintenance

- 补充运行时、消息投影和 SDK 工具测试覆盖，复用现有实现并保持零新增第三方依赖。
