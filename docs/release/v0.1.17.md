# Lume v0.1.17

> 为编码任务加入可追踪的变更审查、检查点恢复和安全回滚能力。

## 🔥 Highlights

- 🔎 Coding Review：可以查看任务实际修改的文件、行数和变更摘要，更快确认编码结果是否符合预期。
- 💾 检查点与回滚：长任务会记录可恢复的状态和事务进度，在安全条件下恢复运行前内容并清理任务创建的文件。
- 🧭 任务连续性：编码回合、工具输出和运行事件携带更完整的上下文，任务中断后更容易继续和审查。

## 🚀 Features

- sidecar：新增 coding change、checkpoint、turn store 和 rewind journal 能力，支持 Git 与非 Git 工作区的受限变更预览。
- sidecar：通过 RPC 暴露编码审查与恢复状态，并完善任务消息版本、线程状态和运行时工具上下文。
- web：新增 Coding Review 右侧面板和变更事件展示，支持从任务界面查看恢复与审查信息。
- sdk：增强 Agent 工具发现、文件检查点、读写缓存和行变更统计，减少重复读取并保护外部修改。

## 🐛 Bug Fixes

- 修复编码任务无法可靠区分直接文件修改、脚本间接修改和验证结果的问题。
- 修复非 Git 工作区的变更预览越界风险，并避免回滚覆盖检查点之后发生的外部修改。
- 修复运行事件和文件工具结果缺少任务回合、恢复状态或变更统计信息的问题。

## 🔧 Maintenance

- 补充编码变更、检查点、回滚日志、回合存储、能力路由、工具工厂和 SDK 文件工具测试覆盖。
- 复用现有 RPC、权限和工作区边界实现，不引入新的第三方依赖。
