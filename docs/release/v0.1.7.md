# Lume v0.1.7

> 更完整、更安全的插件市场与桌面端插件体验。

## 🔥 Highlights

- 🚀 插件市场：浏览、查看详情并安装插件包，插件资源与图标在桌面端得到统一管理。
- 🛡️ 安全与稳定性：强化桌面端权限控制、插件包校验和 Agent RPC 参数验证。
- 🎨 交互体验：优化技能市场、插件安装向导、能力提及与信息图展示。

## 🚀 Features

- feat(desktop,sidecar,web): 支持插件市场浏览、插件包服务与桌面端资源注册，让插件从发现到安装的流程更完整。
- feat(web): 增强技能市场详情、安装向导、插件图标及 Agent 内容展示。

## 🐛 Bug Fixes

- fix(desktop,sidecar,web): 修复插件安装、能力提及和内容渲染中的边界行为，提升跨端一致性。

## 🔧 Maintenance
