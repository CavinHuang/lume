# Lume v0.2.0 — 让 Agent 走出聊天窗口

> 这次更新把 Lume 从“需要一直盯着的对话工具”，推进成一个更接近桌面工作伙伴的本地 AI 工作台：任务状态会跟随你，外部服务可以直接连接，记忆会在后台整理，常用文档与企业消息也能在同一个工作流里处理。

## ✨ 这次更新，一眼看懂

| 能力 | 你会感受到的变化 |
|---|---|
| 🏝️ **Agent 灵动岛** | 离开主窗口后，仍能看到 Agent 的运行状态、待确认事项、计划与最近会话 |
| 🔌 **连接器中心** | 浏览完整服务目录、管理多个账户，并在输入框中 `@` 指定本轮要使用的账户 |
| 🧠 **记忆与洞察中心** | 记忆提取、整理、纠错和恢复在后台完成，所有变化都有证据与记录 |
| 💬 **企业 IM + 文档预览** | 接入飞书、钉钉、企微，并在右侧面板直接阅读 PDF、Word、Excel、PPT 和 CSV |

## 🔥 Highlights

### 🏝️ Agent 灵动岛：任务状态始终在场

Agent 灵动岛会把运行状态、待办、提醒和最近会话带到桌面顶部，不必反复切回 Lume 确认进度。展开后可以直接打开会话或待办；空闲时也能快速开始新任务。

- Windows / Linux 使用轻量透明悬浮窗，支持拖动、顶部吸附和紧凑展开。
- macOS 26+ 优先使用原生刘海面板；原生 helper 不可用时自动回退 Electron 悬浮窗。
- 对紧急确认、计划到期和运行阶段变化进行更及时的状态投影。
- 修复反复展开收起、拖动区域吞掉点击、退出后残留和窗口位置丢失等问题。

相关实现：[#21](https://github.com/CavinHuang/lume/pull/21)、[#37](https://github.com/CavinHuang/lume/pull/37)、[#41](https://github.com/CavinHuang/lume/pull/41)、[#48](https://github.com/CavinHuang/lume/pull/48)

### 🔌 Link 连接器：从“装好了”到“Agent 真正会用”

连接器中心采用目录 + 详情的双栏布局，清楚区分运行时配置和账户授权。连接完成后，可以在会话输入框或欢迎页通过 `@` 选择具体账户，让 Agent 在本轮任务中准确调用它。

- 保留完整 OpenConnector Provider 目录，支持分类、搜索、能力预览和品牌图标。
- 支持多个同类账户，展示已连接与待完成授权状态，并可恢复、重连或删除。
- 支持连接本机内置或已有的 OpenConnector 部署；远程凭据使用现有主密钥加密保存。
- 公网部署仅允许 HTTPS，OAuth 会话按运行时来源隔离，切换部署时会清理过期状态。
- Link 工具改走 MCP 调用链，并补齐动态工具搜索注册，让 Agent 能发现并执行连接器能力。

相关实现：[#32](https://github.com/CavinHuang/lume/pull/32)、[#44](https://github.com/CavinHuang/lume/pull/44)、[#45](https://github.com/CavinHuang/lume/pull/45)、[#46](https://github.com/CavinHuang/lume/pull/46)、[#47](https://github.com/CavinHuang/lume/pull/47)

### 🧠 记忆与洞察中心：后台整理，可见、可控、可恢复

记忆系统完成一次集中升级。Lume 会在不阻塞当前对话的情况下提取和整理记忆，同时保留来源证据、版本链与变更前后内容，方便确认它“记住了什么、为什么记住”。

- 新增统一的记忆与洞察中心，集中查看记忆库、待处理项、活动记录和后台任务。
- 支持主动记忆、纠正、归档、撤销与冲突处理，并在聊天中返回清晰的变更回执。
- 后台提取支持游标、幂等、取消、恢复和重试，应用重启后仍能继续未完成任务。
- 自动生成 Workspace Brief、Capsule 与 Persona；召回过程增加范围、时效和预算控制。
- 旧版 Markdown 记忆会在首次使用时自动迁移，无需手动整理文件。

相关实现：[#31](https://github.com/CavinHuang/lume/pull/31)

### 💬 企业消息与 📄 文档工作台

- 飞书、钉钉、企微支持入站消息触发 Agent、回复闭环，以及 Agent 主动调用对应 CLI；授权状态可在设置中管理。真实企业账号仍需完成各平台凭据配置。见 [#34](https://github.com/CavinHuang/lume/pull/34)。
- 右侧文件面板新增 PDF、DOCX、XLSX、PPTX、CSV 内嵌查看器；PDF 支持翻页、缩放和搜索，核心渲染资源可离线使用。见 [#33](https://github.com/CavinHuang/lume/pull/33)。
- 模型供应商设置改为更紧凑的手风琴布局，多个 Provider 更容易浏览和维护。见 [#35](https://github.com/CavinHuang/lume/pull/35)。
- 深度阅读笔记聚焦单一核心洞察，篇幅更短，减少背景铺垫和重复总结。见 [#42](https://github.com/CavinHuang/lume/pull/42)。

## ⚡ 性能与可靠性

- OpenConnector 运行资源由完整 `node_modules` 改为单一 bundle，体积从约 **187 MB 降至 62 MB**，减少约 67%。见 [#32](https://github.com/CavinHuang/lume/pull/32)。
- 修复 macOS 26 开发模式下 ESM 路径导致的启动崩溃，以及 Node 22 干净环境无法构建 OpenConnector 的问题。见 [#48](https://github.com/CavinHuang/lume/pull/48)。
- 修复 Lark SDK 路径写死导致 sidecar bundle 无法重定位、开发环境无法启动的问题。见 [#40](https://github.com/CavinHuang/lume/pull/40)。
- ripgrep 资源下载失败时，开发模式会降级继续启动，不再被非关键资源阻断。见 [#36](https://github.com/CavinHuang/lume/pull/36)。
- 收紧 Link 远程运行时、OAuth 回调域名、凭据与部署切换边界，降低跨部署状态串用风险。见 [#47](https://github.com/CavinHuang/lume/pull/47)。

## ⬆️ 升级说明

- 本版本没有需要手动执行的破坏性迁移。
- 记忆 V2 会在首次使用时自动迁移旧数据；建议不要在迁移过程中同时手动编辑记忆文件。
- 连接远程 OpenConnector 时，公网地址必须使用 HTTPS；本机 loopback 地址仍可使用 HTTP。
- macOS 26 原生灵动岛不满足运行条件时会自动回退，不影响 Agent 主流程。
