# Lume v0.1.15

> 更可靠的编码工具链与运行时安全，让文件操作、搜索和长任务执行更稳定、更容易审查。

## 🔥 Highlights

- 🚀 编码工具链：文件读写、编辑、搜索和工作树操作得到统一增强，复杂代码任务可以更稳定地执行和恢复。
- 🛡️ 运行时安全：Shell、文件系统和自动化操作的权限判断更细致，高风险命令会在执行前获得明确控制。
- ⚡ 跨平台体验：桌面端内置搜索资源并完善 Windows、macOS 运行时路径与打包校验，减少环境差异导致的问题。

## 🚀 Features

- sdk：增强 Bash、Read、Write、Edit、Glob、Grep 和 Worktree 工具，支持更完整的分页、编码保留、变更检测、任务状态和无匹配结果处理。
- sdk：支持为并行 Agent 传递更完整的工具上下文与运行元数据，长任务结果更容易追踪。
- desktop：桌面端打包内置 ripgrep 与相关资源，并完善原生 AST 和 Bash 命令解析支持。
- sidecar：统一工具运行时的权限分组、Shell 子命令分析和安全规则匹配。

## 🐛 Bug Fixes

- 修复文本文件编辑可能改变 CRLF、UTF-16 BOM 或在外部修改后覆盖新内容的问题。
- 修复搜索无匹配时被误报为工具失败、分页结果被静默截断以及桌面资源路径在不同平台不一致的问题。
- 修复后台 Agent 与任务输出的运行事件元数据不完整问题。

## 🔧 Maintenance

- 补充文件工具、搜索工具、工作树、权限安全、桌面打包和原生 AST 测试覆盖。
- 保持现有依赖与 IPC 约束，不引入新的第三方依赖。
