# Lume v0.0.1

> 首个重新发布的桌面版本，重点是让 macOS 和 Windows 安装包自包含、可更新、启动更可靠。

## 🔥 Highlights

- 🚀 桌面安装包更可靠：macOS Apple Silicon、macOS Intel、Windows x64 都会随包携带 standalone sidecar，不再依赖用户机器上的系统 `node` 或 `bun`。
- 🐛 Windows 启动修复：修复 Windows 安装包里 sidecar 因路径规范化和运行时依赖导致无法连接后端的问题。
- 🚀 插件平台上线：支持插件市场、权限确认、审计日志和 `/reload-plugins` 热加载，让 Agent 能力可以安全扩展。
- 🚀 发布流程重做：CI 会先构建、smoke sidecar、检查本地/远端资产和 `latest.json`，全部通过后才自动发布。

## 🚀 Features

- feat(desktop): 桌面端支持 Tauri 自动更新、启动页和后端健康检查，启动过程会等待 sidecar 真正可用后再进入主界面。
- feat(sidecar,web,shared): 插件平台支持市场源、权限确认、持久化审批、审计日志和插件热加载。
- feat(shared,sidecar,web): MCP 与插件能力接入 Agent 运行时，敏感能力会在调用前触发用户确认。
- feat(web): 右侧面板支持标签、新建入口、拖拽宽度和更清晰的权限提示。
- feat(desktop): release 打包改为 standalone sidecar，通过 Tauri `externalBin` 随应用安装包分发。

## 🐛 Bug Fixes

- fix(desktop): 修复 Windows `\\?\` 路径和裸盘符路径导致 sidecar 启动失败的问题。
- fix(desktop): release 模式只启动随包携带的 sidecar 二进制，避免系统运行时缺失造成 macOS/Windows 安装包不可用。
- fix(desktop,sdk): WebFetch 的 Readability 路径延迟加载，避免 standalone sidecar 启动时触发 `css-tree` 动态资源错误。
- fix(ci): 发布流程统一使用 `RELEASE_TOKEN` 创建和更新 GitHub Release，避免默认 token 权限不足。
- fix(web): 调整启动页节奏、右侧面板按钮位置和标签交互。

## 🔧 Maintenance

- 发布流水线改为单一 draft release：三平台构建上传到同一个 release id，远端资产验证通过后自动 publish。
- 新增发布门禁脚本：package input 校验、compiled sidecar smoke、本地 bundle artifact 校验、远端 release asset 校验。
- 更新发布文档，明确当前支持 macOS Apple Silicon、macOS Intel 和 Windows x64；Linux 桌面包暂不在此发布流程中。
- 发布说明由 `docs/release/v0.0.1.md` 提供，CI 会直接读取该文件作为 GitHub Release body。
