# Lume v0.0.1

> 首个正式版本 — 插件平台、MCP 工具集成、桌面端应用全面上线。

## 🔥 Highlights

- 🚀 插件平台：支持插件安装、权限管理、审计日志，扩展 Agent 能力边界
- 🚀 MCP 工具集成：Agent 可调用外部 MCP 服务器工具，敏感操作需用户确认
- 🚀 桌面端应用：基于 Tauri 的跨平台桌面客户端（macOS / Windows / Linux）
- 🚀 自动化工具：21 个任务模板 + 一键创建，支持例行任务管理

## ⚠️ Breaking Changes

- 无破坏性变更

## 🚀 Features

### 插件平台

- 支持 Skill 市场源与 marketplace 清单，可从多源安装插件
- 完成插件市场后端闭环与前端接入
- 插件敏感能力权限确认 UI：ask → interactive + allow_always 持久化
- 新增 `/reload-plugins` 斜杠命令，支持插件热加载
- 插件审计日志（PluginAuditLog）：操作记录可查询

### MCP 工具集成

- Agent 可调用外部 MCP 服务器工具，自动注册到运行时
- 敏感操作网关（sensitive-gate）：调用前需用户确认
- 支持 per-tool 运行时权限策略
- 启动级网关（authorizeConnect）：连接时校验权限

### 桌面端 (Desktop)

- 基于 Tauri 的跨平台桌面应用
- 自动更新机制（Auto-updater 已签名）
- 启动页（Boot Screen）：分阶段加载，视觉不闪屏
- 文件链接右键菜单：复制路径、打开、预览
- 消息附件卡片接入右键菜单
- 支持右侧面板拖拽宽度

### Web 前端

- Agent 消息极简显示模式：按需展开思考/工具调用/子代理
- PermissionBanner：展示插件敏感能力维度
- 系统工具管理重构为可展开分组面板

### 侧边栏 (Sidecar)

- 插件运行时核心（createRuntimeCoreSession + plugin hooks）
- SensitiveGateResult 扩展 ask 三态（interactive / deny / allow）
- 审批持久化（FilePluginStateStore.appendSensitiveApproval）

### 自动化与工具

- `automation_list`：搜索筛选自动化任务
- `automation_template`：21 个模板 + 一键创建
- `routine` 工具组：routine_read / trigger / update / regenerate

### 模型与渠道

- 新增阶跃星辰 Stepfun 模型（stepfun / stepfun-coding-plan）
- 微信渠道多媒体消息支持（图片/视频/文件发送与接收）

## 🐛 Bug Fixes

- 修复桌面端自动更新签名公钥配置
- 修复 tauri-action 缺少 tauri script 并补全 CLI 构建步骤
- 修复 Windows CI 读取发布说明兼容性
- 修复启动页节奏并平滑阶段过渡
- 修复右侧面板按钮位置与缩放交互
- 修复 release 打包与更新产物

## 🔧 Maintenance

- 发布流程自动化：版本 bump + tag + push + CI 自动构建
- 发布说明生成 skill（agent 自动生成用户视角发布说明）
- CI 自动读取 `docs/release/<tag>.md` 作为 GitHub Release body
- 打包流水线 + 类型修复
- 多项代码重构（提取常量、类型、去重等）
