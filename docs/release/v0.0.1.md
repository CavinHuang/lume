# Lume v0.0.1

> 首个正式版本 — 插件平台、MCP 工具集成、桌面端应用与技能市场全面上线。

## 🔥 Highlights

- 🚀 插件平台：支持插件安装、权限管理、审计日志，扩展 Agent 能力边界
- 🚀 MCP 工具集成：Agent 可调用外部 MCP 服务器工具，敏感操作需用户确认
- 🚀 桌面端应用：基于 Tauri 的跨平台桌面客户端，支持自动更新
- 🚀 技能市场：可从多个技能源（marketplace）浏览和安装插件

## ⚠️ Breaking Changes

- 无破坏性变更

## 🚀 Features

### 插件平台 (Plugin Platform)

- 插件市场支持 Skill 市场源与 marketplace 清单
- 完成插件市场后端闭环与前端接入
- plugin-registry needs_review 审计埋点（Phase 4B）
- attempt 三处审计埋点（sensitive_approval/denial + capability_blocked）
- GET_PLUGIN_AUDIT_LOG RPC handler（审计日志查询）
- plugin-audit-store（jsonl append + read 审计存储）
- 插件敏感能力权限确认 UI（ask → interactive + allow_always 持久化）
- 新增 /reload-plugins 斜杠命令（热加载插件）

### MCP 工具集成

- sensitive-gate 支持 plugin MCP 工具（mcpServer key）
- createRuntimeCoreSession 接入 plugin MCP 网关
- buildPluginMcpManager 接入启动级网关（authorizeConnect）
- PluginRuntimeAssembly 携带 resolved plugin mcpServers
- WorkspaceMcpManager 支持 authorizeConnect 启动级网关
- createRuntimeTools 支持 includeManagementTools + toolMetadata

### 桌面端 (Desktop)

- Tauri 桌面端应用（macOS / Windows / Linux）
- 自动更新机制（Auto-updater 已签名）
- 启动页组件 LumeBootScreen + bootDone 过渡
- 文件链接右键菜单（复制路径、打开、预览等）
- 系统工具管理重构为可展开分组面板
- 消息附件卡片与工作区文件树接入右键菜单
- 右侧面板支持拖拽宽度

### Web 前端

- Agent 消息极简显示模式（按需展开思考/工具调用/子代理）
- PermissionBanner 展示插件敏感能力维度
- 支持文件树拖拽宽度
- 侧边栏 ContextMenu 重构为原生组件
- 健康检查等待 sidecar 就绪后再返回

### 侧边栏 (Sidecar)

- 插件运行时核心（createRuntimeCoreSession + plugin hooks）
- SensitiveGateResult 扩展 ask 三态（interactive / deny / allow）
- FilePluginStateStore.appendSensitiveApproval 审批持久化
- AgentToolPermissionRequest 新增 pluginSensitive 字段
- RELOAD_PLUGINS RPC（复用 LIST_PLUGINS 扫描 + emit CAPABILITIES_CHANGE）
- 新增 Office 工具策略 prompt 与工具定义

### 自动化与工具

- 新增 automation_list 工具（搜索筛选自动化任务）
- 新增 automation_template 工具（21 个模板 + 一键创建）
- 新增 routine 工具组（routine_read/trigger/update/regenerate）

### 模型与渠道

- 新增阶跃星辰 Stepfun 模型支持（stepfun / stepfun-coding-plan）
- 微信渠道多媒体消息支持（图片/视频/文件发送与接收）

## 🐛 Bug Fixes

- 修复桌面端自动更新签名公钥配置
- 修复 tauri-action 缺少 tauri script 并补全 CLI 构建步骤
- 修复 Windows CI 读取发布说明兼容性（shell: bash）
- 修复右侧空面板无法新开标签
- 修复右侧面板按钮位置与缩放交互
- 修复启动页节奏并平滑阶段过渡
- 修复 release 打包与更新产物

## 🔧 Maintenance
