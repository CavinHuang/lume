# L3 Persona 完整用户画像 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Lume 增加 L3 Persona——LLM 综合生成的用户画像（Markdown 白盒 5 段），注入 Agent 上下文，会话结束/correction 后自动生成/增量更新，含 UI 编辑。

**Architecture:** 新建 `memory-v2/persona.ts`（generate/ensure/parse/buildFromRules + 存储 persona.md）。复用 memory-v2 extraction LLM 配置 + markdown-store 原子写。注入 `<persona_profile>` 段（与现有 `<user_profile>` 即时过滤共存）。workflow-hook（run.afterComplete）+ service（correction accepted 回流）触发 ensurePersona。详见 spec `docs/superpowers/specs/2026-08-04-l3-persona-design.md`。

**Tech Stack:** TypeScript · bun:test · memory-v2（claim/markdown-store/paths）· memory-v2 extraction LLM 适配 · Lume IPC 4 层桥 · workflow-hooks · React（MemorySettings）

## Global Constraints

- **测试运行器**：bun:test。单文件 `bun test <file>`；sidecar 全量 `bun run --filter @lume/sidecar test:unit`（`run-unit-tests.mjs` 隔离 mock.module）；typecheck `bun run --filter @lume/sidecar typecheck`（或对应包）。
- **提交风格**：emoji 前缀（✨ feat / 🧪 test / 🐛 fix / ♻️ refactor）+ 中文描述。仅按 plan 的 commit step 提交。
- **fail-open**：所有 persona/LLM/回流失败必须返回空/null + try/catch，绝不阻塞 run 完成。
- **LLM 复用**：persona LLM 调用复用 memory-v2 extraction 模型解析链（`resolveMemoryExtractionModelRefs`），**不引入独立 env**（同周期 1 analyst）。
- **desktop 白名单（周期 1 P0 教训）**：新增的 persona RPC **必须**加进 `apps/desktop/src/renderer-sidecar-methods.ts` 的 `PUBLIC_RENDERER_SIDECAR_METHODS`，否则生产静默失败（`electron-security.test.mjs` 反射 guard 守门）。
- **设计权威**：本 plan 与 spec 冲突时以 spec 为准。
- **代码注释**：中英混用，仿 memory-v2 风格。
