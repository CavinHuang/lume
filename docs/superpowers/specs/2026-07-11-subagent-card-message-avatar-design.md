# Subagent 卡片消息头像移除设计

## 目标

Subagent 卡片展开后的消息流不显示消息正文左侧的圆形 Agent 头像，也不保留头像占位，使思考、工具调用和文本消息直接左对齐输出。

## 范围

- 仅影响 `SubagentInlinePanel` 内嵌消息流。
- 保留 Subagent 卡片标题栏头像。
- 保留展开详情栏中的 Subagent 标识图标。
- 不改变独立子会话页面、主 Agent 消息或其他 `RuntimeEventContentBlock` 使用位置。
- 不改变消息投影、流式追加、工具输出、思考内容和滚动行为。

## 实现设计

在公共消息渲染边界增加一个可选的头像显示控制项，默认行为保持现状。`SubagentInlinePanel` 渲染 `RuntimeEventContentBlock` 时显式关闭消息头像。头像关闭时，消息正文容器同时移除为头像预留的宽度。

不通过 CSS 选择器从父层强制隐藏，因为这种方式会保留或依赖内部布局细节；不复制一套 Subagent 专用消息渲染器，以免与独立会话的流式消息行为分叉。

## 验证

- 组件测试确认 Subagent 卡片向消息渲染器传入关闭头像的配置。
- 现有默认渲染路径不传配置，继续显示头像。
- 运行相关 Web 测试；若控制项涉及公共 TypeScript 接口，再运行 Web 类型检查。

## 非目标与风险

本次不移除卡片标题栏头像，也不调整详情元数据。主要风险是公共渲染器的布局控制误伤其他会话，因此控制项必须默认开启，并只在 Subagent 卡片调用点关闭。
